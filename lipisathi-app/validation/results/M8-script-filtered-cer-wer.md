## What this measures

Unfiltered CER/WER is dominated by insertions of non-target text (Latin letters, digits, punctuation, symbols). This version keeps **only target-script characters** (Devanagari for Hindi, Telugu for Telugu) in both the reference and the OCR text, then computes the usual corpus-level CER/WER.

- It removes noise such as English text and digits. It does **not** remove target-script text from the scene (other signs, posters) or misread characters. Those still count as errors.
- It is an error rate, not accuracy, on an exploratory 12-image set (reference text is user-attested as human verified). Read it alongside the unfiltered numbers and the word-recall diagnostic.
